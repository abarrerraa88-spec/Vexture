# Vexture TikTok Command Center

A lightweight single-page app for organizing multi-account TikTok management in one place.

## Features

- Add and track multiple TikTok accounts
- Schedule content ideas by account
- Track followers + average views with a simple view-rate indicator

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
